Create a new construction estimate for the project described by the user.

Steps:
1. Ask for the project name, location, and type (custom cottage, addition, renovation, commercial, land development)
2. Ask for scope details or reference any attached drawings/specs
3. Use MS 365 tools to list estimating templates on the company SharePoint site
4. Ask the user which template to use as a starting point
5. Pull the template from SharePoint and create a working copy in `estimating/` named after the project
6. If no suitable template exists, create a new Excel workbook with CSI division tabs (Item, Description, Quantity, Unit, Unit Cost, Total) and a Summary tab
7. Add rows for: Subtotal, Overhead (%), Profit (%), Contingency (%), HST (13%), Grand Total
8. Check email for any related RFQs or sub-trade quotes for this project
9. Save the working estimate back to the appropriate SharePoint project folder
