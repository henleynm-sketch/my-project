# Marketing Hub

Root of the marketing workspace. Supports a human-in-the-loop daily workflow built around five future scheduled Routines: Data Pull, CMO Briefing, Content Generator, Networking Assistant, Publisher.

Platforms in scope: Meta Ads, Google Ads, LinkedIn, Instagram, Facebook, X, HubSpot, Mailchimp, Buildertrend.

## Layout

- `content/drafts/` — generated posts, ads, and emails awaiting human approval.
- `playbook/` — the CMO brain: brand voice, ICP, offers, KPIs, guardrails.
- `prompts/` — routine prompt files (added in a later step).
