# Henley Contracting — LinkedIn Networking Toolkit

Tools and templates to grow Henley Contracting's brand presence across Oshawa, Whitby, and Kawartha Lakes through strategic LinkedIn networking.

## What's Included

### Templates (`templates/`)
- **`connection_requests.md`** — Copy-paste connection request messages for realtors, trades, mortgage brokers, designers, local businesses, and more (all under LinkedIn's 300-char limit)
- **`follow_up_messages.md`** — Follow-up messages to send after someone accepts your request
- **`content_calendar.md`** — Weekly posting schedule, content ideas, post templates, and hashtag strategy
- **`networking_strategy.md`** — Full strategy guide: target audiences, weekly action plan, profile optimization checklist, LinkedIn search queries, and success metrics

### Scripts (`scripts/`)
- **`contact_tracker.py`** — CLI tool to track contacts, follow-ups, and outreach stats
- **`message_generator.py`** — Interactive tool to generate personalized LinkedIn messages

## Quick Start

### Generate a personalized message
```bash
python scripts/message_generator.py
```

### Track your outreach
```bash
python scripts/contact_tracker.py add        # Add a new contact
python scripts/contact_tracker.py followups   # See who needs a follow-up today
python scripts/contact_tracker.py list        # View all contacts
python scripts/contact_tracker.py update      # Update a contact's status
python scripts/contact_tracker.py stats       # See your outreach stats
python scripts/contact_tracker.py export      # Export to CSV
```
